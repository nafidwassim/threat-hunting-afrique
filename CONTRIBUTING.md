# Contribuer (équipe 3pH)

Le règlement impose que tout développement (profils, collecteurs, scripts, modèles, requêtes) soit versionné ici.
- Une branche par membre et par tâche : `prenom/sujet` (ex. `wassim/anomalies-vpn`). Pas de commit direct sur `main`.
- Pull request relue par un autre membre avant fusion ; `python -m pytest -q` doit passer.
- Chaque artefact significatif ajoute une ligne à `journals/journal_validation.csv`.
- Chaque session de collecte dark web ajoute une ligne à `journals/journal_collecte_darkweb.csv` AVEC la validation de l'encadrant.
- Jamais de données réelles, d'identifiants, de clés ou de contenu illicite : données synthétiques et domaines `.example` seulement.
